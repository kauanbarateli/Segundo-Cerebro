Credenciais de autorização são guardadas cifradas no servidor para permitir sincronizações autorizadas. Você pode pedir a desconexão no aplicativo e revogar o acesso nas [permissões da sua Conta Google](https://myaccount.google.com/connections). Revogar a autorização impede novos acessos, mas não deve ser confundido com eliminação instantânea de toda cópia já sincronizada; pedidos de exclusão precisam ser atendidos conforme o procedimento e as retenções aplicáveis.

O uso e a transferência das informações recebidas das APIs Google devem observar a [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), incluindo Limited Use. Esses dados se destinam à função de agenda visível, sem venda, anúncios direcionados, perfil de crédito ou treinamento de modelos gerais de IA. Leitura humana não é finalidade comum; eventuais acessos precisam se limitar às hipóteses permitidas pela política, como autorização afirmativa específica, segurança ou obrigação legal. A integração não autoriza acesso a Gmail ou Drive.
