# Atualizações editoriais

O quadro usa somente conteúdo aprovado e publicado em `src/components/features/atualizacoes/content.ts`. Para publicar ou retirar um item, altere a lista em um PR revisado. Use ID estável, título, resumo, estado, data ISO e ordem; itens em `released` precisam de referência verificável à entrega. Não inclua feedback privado ou rascunhos sigilosos. A lista vazia é válida.

Quando houver gestão editorial no ADM, migre os IDs e estados para a nova fonte e troque a leitura de forma controlada, mantendo uma única fonte ativa. A rota exige sessão real e não expõe ações de edição.
