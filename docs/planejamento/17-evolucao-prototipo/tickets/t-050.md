## Escopo

- Editor expressivo com toolbar para títulos/marcas/listas/citação/alinhamento/link/undo-redo; componentes neutros sem import feature→feature.
- Contrato aditivo de documento JSON validado + texto de busca + revisão/CAS; compatibilidade com texto legado e drafts existentes.
- Promoção leva documento integral à Página com origem, anexos e wiki-links por ID; tarefa recebe descrição textual e origem.
- Namespaces de vínculos: linked_capture_ids nunca vira wikiLink.target_id de Página. Mapear destino promovido por origin_capture_id; preservar alvo ainda não promovido como vínculo tipado de Captura, sem associação por título.

## Critérios de aceite

- [ ] Texto legado abre sem interpretar HTML; todos formatos persistem round-trip; colagem/links perigosos são normalizados/rejeitados.
- [ ] Cliente antigo/edição concorrente não sobrescreve documento novo silenciosamente; erro preserva draft e permite retry.
- [ ] Promoção repetida cria uma página, mantendo formatação/ID/origem; rename mantém vínculos; anexos continuam privados.
- [ ] Toolbar mantém seleção/foco; Ctrl+K local não dispara busca global; mobile permite lista↔editor; refresh e troca de usuário respeitam drafts.
- [ ] A→B promovido em ambas as ordens, renomeado e repetido mantém relações corretas sem IDs de Captura usados como Página.
