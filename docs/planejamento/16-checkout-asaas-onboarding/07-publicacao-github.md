## O que o mantenedor prepara

Use apenas o [checklist humano 06](06-preparacao-do-mantenedor.md). Ele separa Asaas PF/sandbox, destino isolado de homologação, transporte/remetente/DNS, domínio/Pro, preparação OAuth, oferta/atendimento e política de privacidade/retenções. O bloco final serve como resposta de status sem credenciais.

Os agentes cuidarão de código, testes, adapters, SQL versionado, cenários e evidências quando a execução for solicitada. Configurar webhook, aplicar migrations novas e inserir variáveis finais depende dos destinos/contratos que eles apresentarão; não é possível dar esses passos finais por antecipação com endpoints inventados. Links/senhas/consentimento e aceite de lançamento conservam os checkpoints humanos.
