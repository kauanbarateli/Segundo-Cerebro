# Capturas atuais do snapshot

Coleta offline em contexto isolado, a partir da cópia integral do protótipo. **Não são capturas da aplicação de produção.** Veja [manifesto](manifest.json) com horário, rota, tema, viewport e erros. 55 imagens; nenhuma exceção JavaScript e nenhum overflow horizontal global na coleta. A conferência visual por amostragem incluiu Financeiro desktop claro, Hábitos mobile escuro e Kanban desktop escuro; não é uma certificação de acessibilidade de todas as telas.

As imagens full-page mantêm a barra fixa na posição do viewport inicial: sua aparição no meio de uma captura longa não significa que seja uma linha do conteúdo. Para avaliar rolagem e foco, navegue no snapshot. Os estados de entrada/meta usam as regras demonstrativas; aplique as decisões de reserva/cadência do doc03 ao produto.
