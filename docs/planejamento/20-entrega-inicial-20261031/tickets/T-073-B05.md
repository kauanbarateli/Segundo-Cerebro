# T-073 — Mostrar atualizações em quadro autenticado e versionado

## What to build

Usuário autenticado consulta melhorias em cinco estados num quadro enxuto. Conteúdo editorial versionado permite uma entrega útil antes de existir o novo ADM.

**Chave:** B05 · **Frente:** B · **Fase:** 1 · **Esforço relativo:** S–M.
**Estado:** ready-for-agent, respeitando bloqueios.

## Acceptance criteria

- [ ] Exibir Planejado, Em análise, Em andamento, Em fase de testes e Lançado com navegação acessível; usuário não muda estado ou conteúdo.
- [ ] Fonte editorial contém IDs estáveis, títulos/resumos/estado/data/ordem e apenas material publicável. Nenhum feedback, identidade, rascunho sigiloso ou segredo no repositório/bundle.
- [ ] Rotas de leitura exigem autenticação atual; sem endpoint administrativo de escrita, nova tabela ou dependência artificial do cadastro público.
- [ ] Cards Lançado apontam para entrega factual; quadro pode iniciar vazio com mensagem útil. Não anunciar planejamento como recurso liberado.
- [ ] Desktop/mobile não exigem drag e não geram overflow global; estados claros e ambos os temas. Link Enviar sugestão só aparece se Feedback estiver disponível.
- [ ] Documentar como publicar/retrair via PR e como os mesmos IDs migrarão para fonte administrável futura, sem criar segundo roadmap concorrente.

## Blocked by

Nenhum bloqueio técnico. Pode iniciar na fase 1.

## Validação

Teste de autenticação/rota e conteúdo validado; inspeção dos cinco estados, vazio, mobile, teclado e temas. Usar apenas dados editoriais aprovados/publicáveis.

## Fora deste ticket

CMS, API de escrita, voto, roadmap público, resposta de feedback e duplicação de superfícies.
